# Research results

The measured English AgRoBERTa contribution is stored under [Phase 1 results](../phase_01_original_baseline/results/baseline_results.json), with [comparison CSV](../phase_01_original_baseline/results/model_comparison.csv), [330 final test predictions](../phase_01_original_baseline/results/test_predictions.jsonl), [training logs](../phase_01_original_baseline/results/training_logs.csv) and [plots](../phase_01_original_baseline/results/plots/README.md).

The primary scores use SQuAD-style English normalization for original-paper comparison. A separate [shared-protocol rescore](../phase_01_original_baseline/results/shared_protocol_results.json) supports later multilingual comparisons without conflating metric definitions. Phase 1 is partial: XLM-R training/checkpoint publication are pending. Other phases remain pending. `status.json` is a tracker pointing to experimental evidence, not itself a model evaluation.
