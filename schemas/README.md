# Shared data contracts
One UTF-8 JSON object per nonblank JSONL line. QA schema applies to normalized English, translated and native records. `id` identifies a parallel question group; `(id, language)` uniquely identifies a record. Prefix IDs from different datasets to avoid collisions. `source_document_id` is stable across translations. Answers are nonempty extractive text with a zero-based Unicode character offset. Unanswerable QA is outside this starter contract. Additional provenance fields are allowed.

The shared validator implements required QA fields, types, spans, duplicate detection and within-file split checks without a JSON Schema dependency. JSON Schemas document interchange; corpus schema validation and cross-file leakage audits must be performed separately before training. Prediction records contain id, language and prediction_text (an empty string is a valid model abstention). Dataset cards and review CSVs preserve provenance outside the minimal record schema.
